# Projekt Runo

Tere!

Tegemist on veebilehe projektiga Runo programmeerimise kursuses. Veebileht on olemuselt investeerimise simulaator, kus kasutaja saab ülevaate valitud varaklasside väärtustest maailmaturul ning saab võimaluse ise simuleerida läbi investeerimine etteantud ajavahemikul. 

Projekti _WIP_ disainifaasi saab vaadata [figma keskkonnas](
https://www.figma.com/proto/uMm7lVRfkVi77DbS7diKZX/programmeerimine?node-id=1-3&p=f&t=Yi9TJqNgzaky0k2d-0&scaling=min-zoom&content-scaling=fixed&page-id=0%3A1)

Alfaversiooni vahearuanne:

Koostöö sujub hästi: arutame regulaarselt projekti funktsioonide ja toimimise üle. Disaini ja kujundusega tegeleb Kevin, veebilehe kujundusega Roland, ühiselt tegeleme Pythoni koodi osaga. Projekti üldine ajakulu on olnud 10+ tundi. Edasised plaanid on päriselt Pythoni koodimisega alustada. Hetkeseisuga tehisaru kasutanud CSS puhul omaduste otsimiseks ja meelde tuletamiseks.
